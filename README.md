# Warmly

Evidencias del levantamiento de requerimientos y prototipo de Warmly, el CRM para WARMIENERGY S.A.S.
Proyecto parcial de Ingeniería de Software I (ESPOL), equipo GrupAP.

- `01-elicitation/`: guía de entrevista y análisis de los sistemas que la empresa ya usa.
- `02-user-stories/`: historias de usuario con criterios de aceptación y el backlog priorizado con MoSCoW.
- `03-prototype/`: prototipo navegable y capturas de cada pantalla.

Para ver el prototipo, abre `03-prototype/index.html` en el navegador. Las pantallas móviles están en `#m-hoy`, `#m-lead`, `#m-oport` y `#m-cliente`.

Integrantes: Carlos López, Ángel Pilataxi, Sebastián Barco, Iván Cedeño y Dilan Morales.
